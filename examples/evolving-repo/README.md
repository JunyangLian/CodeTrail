# 仓库演化与可靠执行演示

用户目录通过 normalize_user_id 规范化标识，再经 lookup_user 查找。
当前实现故意包含空格处理与 Unicode 大小写规范化缺陷。

任务：先建简短计划并运行 `python -B -m unittest discover -v`，定位跨文件
契约，只修复 directory.py，然后执行同一命令验证。把可复用的测试入口
作为带来源的候选记忆，等待操作者确认。

演示包含 8 条 unittest。它是新增的产品演示素材，不计入历史冻结评测。
离线模式使用明确标识的脚本化模型帧，真实文件修改、测试、审批和隔离
仍通过同一 Harness；不能把离线模式报告为模型自主修复成功率。
